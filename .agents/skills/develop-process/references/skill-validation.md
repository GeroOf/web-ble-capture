# 指示とスキルの検証

```sh
npm run skills:check
npm run skills:test
```

`skills:check` は名前・説明、`@path` 参照、`npm run` のスクリプト名、参照文書への読み込み経路を検査する。`skills:test` は正常・異常入力と CLI の終了コードを確かめる。指示の読み合わせでは、依頼ごとの適用条件、権限、必須検査、完了条件を確認する。

Codex App Server を使える場合は `skills/list` の `cwds` に対象ディレクトリを指定し、`forceReload: true` で読み込み結果とエラーを確認する。

適用条件、実行順、完了判断を変えたときは、変更後の一式を隔離したコピーに置き、GPT-6.2 Sol で変更に対応する依頼を試す。評価する条件を先に決め、モデルに渡すのは依頼と必要なファイルに絞る。適用条件を変えた場合は対象外の依頼も試す。

コマンドの実行順、終了コード、成果物の差分は固定した期待結果と照合する。既存の検査で確認できる項目は再利用する。指示の適用や判断の妥当性は実行記録と成果物をレビューする。使用したモデル、確認結果、未確認の項目を作業ログに残す。
