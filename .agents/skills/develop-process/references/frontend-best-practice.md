# UI・BLE の設計と検証

- 両ロケールの初期 HTML と JavaScript 無効時の案内を確認する。ブラウザ API はクライアント側で呼ぶ。
- 既存のコンポーネント、配色、余白を使う。キーボード操作、入力ラベル、進行・失敗の表示、モーダルへのフォーカス移動と復帰を確認する。
- API 非対応時の案内と、機器選択の取り消し、権限拒否、接続失敗、切断、通知停止からの復帰を確認する。切断・解除で通知を止め、古い応答が次の接続に影響しないことを確かめる。
- データ変換と状態遷移は Vitest で確認する。主な画面・BLE 操作は実ブラウザで確認する。`@tests/e2e/app.test.ts` と `@tests/e2e/helpers.ts` の模擬 BLE を使い、入力・応答・時刻を必要に応じて固定する。実機を使った場合は環境と確認範囲を記録する。
- 描画負荷、メモリ、配信 JS に影響する変更では該当項目を計測する。
