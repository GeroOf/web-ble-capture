# BLE機能拡張と確認モード

## 要求と受け入れ条件

- ペリフェラル検索: 名前の完全一致・前方一致、サービスのプリセットとカスタムUUID、追加GATTサービスの入力検証、ブラウザの選択画面・接続・探索の状態表示。キャンセルは通常操作として復帰し、失敗後も再試行できる。
- GATT: 能力に合う Read、Write with response / without response、Notify / Indicate、記述子の探索・読み書き。入力はHexまたはUTF-8、最大512バイト。操作の失敗で接続画面を失わず、購読と接続を終了するとイベントを解除する。
- ログ: Hex+ASCII、Hex、ASCII、UTF-8、10進数、2進数、Base64、16bit数値LE/BE、JSONの10形式と、時計・ISO・経過時間の表示。表示した形式でコピーし、不適合なデータを隠さない。最新1000件、バッファの範囲と不変性、自動スクロールの切り替えを検証する。
- 確認モード: 画面設定と `PUBLIC_BLE_DEMO=true` の初期設定で有効化。ユーザー操作で仮想ペリフェラルに接続し、同じ探索・GATT・ログUIを使う。読取・書込・記述子・通知を試せ、対応外ブラウザでも動く。実機との違いを表示し、実機APIを呼ばない。
- 制約: 固定技術スタック、SSG、ユーザー操作、バックエンド通信なし。デバイス情報・接続状態・パケットは永続化せず、履歴はタブ内メモリだけとする。既存IndexedDBのデータは変更・削除しない。一般的な表示設定とUUIDエイリアスだけを保存する。
- 完了: 単体、実ブラウザE2E、型検査、lint・書式、SSGビルド、設計・ソース・セキュリティのレビューが対象内で合格する。

## 調査と設計

2026-10-04 に現行コード、仕様、Web Bluetoothの型定義、[Chrome公式資料](https://developer.chrome.com/docs/capabilities/bluetooth)を確認した。ブラウザが提供する選択画面、名前・サービスフィルター、GATT操作を対象とし、受動的な無制限検索や無線上の全パケットの傍受は扱わない。検索には必ずクリックを使い、名前フィルターでも追加サービスのアクセス許可を指定する。

実機と仮想機器は必要なGATTメソッド・イベントだけの共通型を使う。実機はWeb Bluetooth API、確認モードはメモリ上の固定機器と決定的なサンプル値で実装する。確認モードは必要時だけ読み込む。GATT操作を直列化し、旧接続の遅延応答と解除後のイベントを現在のセッションへ混入させない。

検索入力・パケット変換はUIから独立した純粋関数にする。キャラクタリスティックの識別はUUID単独ではなくサービスとインスタンスの位置を含め、同じUUIDの複数インスタンスを混同しない。通知のコールバックは接続マネージャーが所有し、再描画に依存しない。

現行のデバイス名入りセッションとIndexedDB保存、外部分析スクリプトはAGENTSの制約と矛盾する。今回変更する接続・ログ経路では保存をタブ内メモリへ移し、外部分析を呼ばない。既存ファイルと既存ブラウザデータは削除しない。

設計レビューでは、実機の選択は同期したユーザー操作から開始すること、確認モードでも自動接続しないこと、書込の能力・形式・サイズを検証すること、切断・取消と遅延応答の競合、入力のテキスト表示、保存・通信の禁止を確認した。受け入れ条件と検証計画に照合し、実装前の自己レビューは合格。

## 検証計画

単体で検索オプション・入力の境界、全ログ形式、DataViewの部分範囲、メモリの上限、GATTの直列化・購読解除・遅延接続、確認モードの読み書き・通知・切断を確認する。E2Eでは英日、名前・サービス条件、キャンセル・再試行、実機APIの模擬機器と確認モード、Read/Write/Descriptor/Notify、全表示設定、環境変数による初期設定、再読込時の非永続化、外部要求なしを確認する。実機BLEの互換性は別の未実施項目として記録する。

## 実施・検証・レビュー

実装は検索・GATT・パケット変換を分け、確認用機器を動的に読み込む。名前の検索条件は保存せず、保存する値は接続モード・表示設定・手入力したサービスUUID・エイリアスだけ。接続・ログ・履歴はメモリ上だけで、既存IndexedDBへアクセスしない。外部分析コードとイベント送信も停止した。

主な変更ファイル:

- `src/lib/gatt-types.ts`、`ble-client.ts`、`ble-input.ts`、`ble-error.ts`: 共通型、検索入力、直列化したGATT操作、取消・遅延応答・購読解除、安全なエラー表示。
- `src/lib/demo-ble.ts`: Batteryと確認用サービス、Read/Write/Descriptor、決定的な自動・手動サンプル通知。実機API呼出なし。
- `src/lib/packet-format.ts`、`store.ts`、`storage.ts`: 10表示形式と3時刻形式、部分バッファの複製、1000ログ・20セッションの上限、タブ内履歴と一般設定。
- `src/components/App.tsx`、`DeviceExplorer.tsx`、`LogConsole.tsx`: 検索・接続状態、GATT操作、表示・コピー、自動スクロール、確認モード。
- `Dialog.tsx`、`HistoryModal.tsx`、`AliasManagerModal.tsx`: キーボード操作とフォーカス復帰、メモリ履歴、UUID入力検証。エイリアスの解析結果を再利用し、パケットごとの再解析を避ける。
- `CapturePage.astro`、両ページ、`Layout.astro`、`analytics.ts`: 静的な初期案内、環境変数、非対応ブラウザでの確認モード、外部分析の停止。
- `feature-messages.ts`、`i18n.tsx`: 英日両方の操作・エラー・表示形式。
- 単体テスト5ファイルと `tests/e2e/app.test.ts` / `helpers.ts`: 入力・変換・メモリ・接続マネージャー・確認モードの単体、実ブラウザの全操作。
- `docs/spec.md`、`README.md`、本ログ: 現行仕様、確認モードの使い方、結果と制約。

レビュー・修正ラウンド:

1. 設計: ユーザー操作、共通GATT型、ログ形式、確認モード、通信・保存制約、取消とリソース解放を照合して合格。
2. 型・ソース: readonly検索フィルターの組み立てと、テストの判別共用型・ArrayBuffer型を修正。Hexの半バイト分割や途中の0xを拒否し、書込時も値を複製。全型検査のエラー・警告・hintは0。
3. 実ブラウザ: 初回15件中8件失敗。選択欄のラベルを明示し、ダイアログのフォーカス・Escape処理を描画時に取り付けた。修正後15件合格。
4. ソース・セキュリティ: 同じGATTサーバーを再接続する際も操作を直列化し、旧接続の遅延応答を破棄。Indicateだけの能力、取消後に成功する購読もテスト。既知のGATT設定・privacy値への書込はUI/APIで禁止し、[標準blocklist](https://raw.githubusercontent.com/WebBluetoothCG/registries/master/gatt_blocklist.txt)と照合した。Nativeの権限拒否は接続画面を維持して回復する。入力とパケットはテキストとして表示し、外部送信・IndexedDB・識別情報の自動保存・生のエラーログが本番コードにないことを確認。対象内の未解決指摘なし、合格。
5. 追加確認: 英日で確認用記述子を読み書きし、制御したブラウザ時計で自動通知と停止を確認。モバイルの横方向のはみ出しと重複したアプリがないことをDOMで確認し、デスクトップ・モバイルの画面も目視確認。15件合格。
6. 環境変数: 保存済みの実機モードがあってもPUBLIC_BLE_DEMO=trueを明示した時は確認モードで開始するよう、初期設定の優先順位を修正。再読込と実機API未呼出をE2Eで確認し、15件すべて合格。

## 例外と残課題

Git操作、既存ファイルの削除、デプロイ、パッケージの追加は行わない。未修正版の既存依存脆弱性と公開環境のCSPは別に記録し、機能テストからアプリ全体の安全性を推定しない。

依存・lockfileは初期状態と同一。[http-cache-semanticsのadvisory](https://github.com/advisories/GHSA-ch52-4w7c-c8xp)は既存のAstroビルド経路にあり、前回の更新で記録した未修正版の検出が残る。今回の確認モード・GATT操作によるバックエンド経路は追加していない。上流の修正後に再診断が必要。公開配信設定のCSPと実機は未検証。

## 完了確認

要求した検索UX、GATT機能、ログ表示形式、設定・環境変数での機器不要の確認機能を、現行ソースと実行結果で照合した。最終の型検査・lint・書式・89単体テスト・15 E2E・SSGの通常／確認設定が合格し、対象内の未解決指摘はない。依存とスキルは不変、ファイル削除は0件。確認モードは分離した動的JSチャンク（3195バイト、gzip1237バイト）で、全JSチャンクの合計は90967バイト、gzip29190バイト。画面の確認画像と監査結果は作業用の一時ディレクトリに保存した。実機と公開配信環境、既知の上流依存の未修正版は上記の制限として残る。
