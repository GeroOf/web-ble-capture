# 作業ログ: 多言語化対応

**日時**: 2026-04-12 01:21:49

## 実施内容

- 日本語 (`/ja/`) と英語 (`/en/`) の 2 ロケールを持つ静的ページ構成を追加
- 共通 i18n 辞書と Preact Context を導入し、トップ画面、接続後 UI、履歴モーダル、UUID エイリアス管理、noscript / 非対応ブラウザ文言を日英化
- ログとエラーを文字列保存から「メッセージキー + パラメータ」対応へ拡張し、履歴表示でも現在言語で再解決できるようにした
- SEO メタ情報と `sitemap.xml` をロケール別 URL 前提へ更新
- Vitest に i18n のキー整合性と文言解決のテストを追加

## 技術的判断ポイント

- ルーティングはクライアント切替ではなく Astro の静的ルート (`/ja/`, `/en/`) を採用し、初期 HTML と SEO メタをロケール単位で確定できる構成とした
- ログ永続化は既存データを壊さないことを優先し、`message` を残したまま `messageKey` / `messageValues` を追加する後方互換型にした
- 言語選択は URL を唯一のソースとし、localStorage に locale を保存しないことで SSG と canonical の整合を保った

## 残課題

- Oxc formatter 実行を想定する開発プロセスだが、このリポジトリの利用可能バイナリは `oxlint` のみで formatter 実行手段が存在しなかったため、本作業では format 工程を例外扱いとした
