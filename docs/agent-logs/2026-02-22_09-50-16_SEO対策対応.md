  - （`oxlint` で `<script />` や `set:html` のパースエラーが出たため、HTML標準の終了タグ `<script>...</script>` 等を用いて回避するように実装）
- `src/pages/index.astro`
  - `<Layout>` コンポーネント呼び出し時の `title` を削除し、Layout に委譲するよう変更

## 技術的判断ポイント

- 単一ページのアプリケーションであるため、新たに外部の Astro 用プラグイン等のライブラリは導入せず、標準機能での実装と public フォルダへの静的ファイルの直接配置を採用
- セキュリティのため `dangerouslySetInnerHTML` や `set:html` を使わず、スクリプト要素の子として直接 `JSON.stringify` を埋め込むことで、セキュリティポリシーを満たしつつ Linter エラーも回避
