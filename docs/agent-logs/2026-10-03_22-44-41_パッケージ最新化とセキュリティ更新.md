# パッケージ最新化とセキュリティ更新

## 要求・調査・設計

依頼は利用パッケージの最新化とセキュリティ更新。固定技術スタック、SSG、クライアントだけの BLE 処理を維持し、実行環境も manifest / lockfile と一致させる。依存の互換性を無視する `--force` / `--legacy-peer-deps` は使わない。

2026-10-03 に npm 公式 registry の latest・peerDependencies・engines・dist・公開日時・配布リポジトリ・管理者を確認した。現在の npm 設定は npm.flatt.tech、既存 lockfile は同配布元と registry.npmjs.org が混在している。今回は公式 registry を明示し、新しい一時ディレクトリでインストール時スクリプトを抑止して解決・取得する。旧 node_modules は削除せず退避する。

確認した更新候補は Astro 7.3.5、@astrojs/preact 6.0.5、Signals 2.11.3、Tailwind / Vite plugin 4.3.3、Vite 8.3.2、Vitest 5.0.3、jsdom 30.1.1、oxlint 1.86.0、oxfmt 0.71.0。@types/web-bluetooth は0.0.21が最新。Preact 最新11.0.0は公式連携の peer `^10.6.5` に合わないため、対応範囲の最新10.29.8に更新する。

型検査の @astrojs/check 0.9.10 は TypeScript 5 / 6 に対応し、最新7は範囲外。対応する6系の最新版を追加する。実ブラウザ検証には Playwright 1.63.0 とインストール済み Google Chrome を使い、テストの実行は Vitest に統一する。開発依存だけを追加し、配信 JS へ含めない。

設計レビューでは peer・Node の条件、インストール時処理、削除禁止、検証の範囲を確認した。Node 26.10.0 / npm 11.19.1 で候補の条件を満たし、対応範囲の安定版を使う方針は合格。実装・ソース・セキュリティの再レビューは最終ファイルで実施する。

## セキュリティ調査

更新前の公式 registry による `npm audit --include=dev --audit-level=low --json` は終了コード1、high 2件（http-cache-semantics 本体と Astro の依存影響）。[GHSA-ch52-4w7c-c8xp](https://github.com/advisories/GHSA-ch52-4w7c-c8xp) は4.2.0以下に影響し、修正版はない。npm が提示した Astro 2.10.9 へのダウングレードは、固定構成と現在のアプリに適合しないため行わない。最新化後も診断し、実際の利用経路と配信物への含有を確認する。未解決を検出0件とは記録しない。

サプライチェーンの確認は、公式配布 URL、integrity、署名・provenance、インストール時スクリプトとそのコード、依存経路を対象とする。署名・診断の成功だけで悪意の不在は断定しない。
