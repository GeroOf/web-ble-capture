# 作業内容表題: OGP画像が表示されない問題の修正

## 実施内容

X や Slack などでリンクをシェアした際に OGP (Open Graph Protocol) で指定される画像（`og:image` および `twitter:image`）が表示されない不具合に対応した。

- `public/og-image.png` としてアプリのサムネイル画像（ダークテーマのダッシュボードイメージ）を新規生成。
- `src/layouts/Layout.astro` に `og:image` と `twitter:image` のメタタグを追加。

## 変更ファイル一覧

- `[NEW]` public/og-image.png
- `[MODIFY]` src/layouts/Layout.astro

## 技術的判断ポイント

- `<meta property="og:image" content={`${siteOrigin}${basePath}/og-image.png`} />` のように絶対URLとなるように動的にオリジン・ベースパスが付与される仕組みを用いて実装。これにより、GitHub Pagesのサブディレクトリ配信などでも画像パスが正しく解決される。
- Twitter Card の種類は既存の `summary` に適した正方形・アスペクトフリーなサイズと配置を想定。

## 検証結果

- oxlint: 0 errors
- astro build: 成功 (静的エンドポイントからOGPタグが正しく出力されていることを確認)
