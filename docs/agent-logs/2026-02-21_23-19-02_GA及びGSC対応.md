## 技術的判断ポイント

- SSG において、ビルド時の環境変数に基づいてタグを含めるか省略するかを判断できるよう `import.meta.env.PUBLIC_*` を採用（これによりハードコーディングを回避し、任意の環境に合わせたフレキシブルな運用を実現）
- React 依存を避けるため、Astro の標準である `is:inline` と `<script define:vars={{ gaId }}>` によるピュアな JS で gtag を挿入
