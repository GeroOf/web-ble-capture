# 作業ログ: 多言語URL修正

**日時**: 2026-04-12 01:45:57

## 実施内容

- 多言語 URL 構成を「英語 `/`、日本語 `/ja/`」へ変更
- ルートページを英語版の正規ページへ差し替え、日本語ページは `/ja/` のみ静的生成する構成へ修正
- `hreflang`、`x-default`、サイトマップ、locale パス生成関数、関連テストを新 URL 構成に合わせて更新
- `npx tsc --noEmit` が通るよう `astro.config.mjs` の `process.env` 参照を型安全な形へ補正

## 技術的判断ポイント

- 既存の i18n 実装を崩さず、locale ごとの URL 生成のみ `getLocalePath` に集約して `/` と `/ja/` の差分を吸収した
- `x-default` は既定言語である英語 `/` を指すよう変更し、検索エンジン向けの正規導線を root に揃えた
- 既存ファイル削除禁止の制約に合わせ、`src/pages/[locale]/index.astro` は維持したまま `ja` のみ生成する形に留めた
