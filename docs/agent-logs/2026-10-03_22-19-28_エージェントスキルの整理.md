# エージェントスキルの整理

## 要求と設計

対象は `.agents/skills` の開発スキルと、参照・検証の実行に必要な設定。GPT-6.1 Sol 向けに短い適用条件、明確な成果、必要時だけ読む参照を使う。アプリの機能変更や依存パッケージの更新は対象外。

受け入れ条件:

- 要求分析、調査、設計、設計レビュー、開発（プロダクト・ユニット・E2E）、Linter / Formatter、ソースレビュー、セキュリティレビュー、セキュリティアップデート、テスト実行を共通手順に含める。
- 依存パッケージの脆弱性・サプライチェーン攻撃とアプリ自身の脆弱性をそれぞれ評価し、更新後も検証する手順を定める。
- スキルの適用条件を明確にし、造語・スラング、重複、過去の経緯の記述を除く。
- 決定的な構造検証と失敗例のテスト、実際の Codex 読み込み、GPT-6.1 Sol による独立した内容・行動レビューを行い、全レビューを合格させる。

構成は `develop-process` 1スキルとする。共通工程は `SKILL.md`、UI・BLE、セキュリティ、スキル自身の検証は個別の参照文書に置く。補助スクリプトは Node.js の標準モジュールのみを使用し、検証テストには既存の Vitest を使う。`package.json` に検証コマンドを追加し、AGENTS.md の実在しない `.agent` 参照を `.agents` に修正する。

文書だけの変更なのでプロダクト実装、アプリのユニットテスト追加、アプリ E2E 開発、アプリの依存更新・脆弱性修正は適用外。追加するハーネスはユニットと CLI のテストを実施する。製品の E2E・実機 BLE の結果をこの検証から主張しない。
