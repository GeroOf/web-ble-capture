# OG画像の更新

## 要求と設計

- 要求: `public/og-image.png` を最新の内容へ更新する。
- 現状: ファイルは存在するが、旧接続画面の2536×1498 PNGだった。直前に検証した最新画面ではGATTのRead・Write・通知、複数のログ表示形式、BLE機器不要の確認モードを提供している。

- 保存先: `public/og-image.png`。旧画像とLayoutは `/private/tmp/web-ble-og-update-pEuz54/` に複製済み。
- 対象外: アプリの操作・BLE通信・依存関係・デプロイ。仕様書の動作は変更しない。
